2. 財務大額出金「雙人覆核機制 (Four-Eyes)」

單一出款超過 50,000 THB 需兩名不同權限角色（客服初審 + 財務主管終審）核可；禁止同一帳號自審自批。

技術交付：RBAC 狀態機（Pending -> Approved1 -> Approved2）
驗收指標：杜絕單一內鬼或帳號失竊直接執行批量代發。
P1 架構重構

3. 集中式不可變審計日誌 (WORM Audit Log)

所有手動調帳、玩家密碼重設、代理分潤比率變更事件，必須同步加密傳輸至隔離日誌伺服器，禁止覆蓋刪除。

技術交付：Elasticsearch + Logstash + AWS S3 Object Lock
驗收指標：日誌留存至少 180 天，具備數位簽名完整性校驗。
P0 立即執行

4. 金流多通道智能健康探針與自動熔斷

每 30 秒自動探測 PromptPay 與各三方商戶號可用率，連續 3 筆入金超時或回報失敗，系統 2 秒內自動切換至備用通道。

技術交付：動態權重智能路由演算法 (Smart Payment Router)
驗收指標：商戶號遭凍結時前台充值通道無感切換，掉單率降至 0.05% 以下。

5. 動態微額隨機碼對帳機制（小數點尾數）

玩家充值 1000 THB 時，動態生成 1000.17 或 1000.42 THB 訂單，泰國 PromptPay 掃碼後自動秒級精準銷單，免附言校對。

技術交付：小數點訂單碰撞分配池 (TTL 10分鐘釋放)

6. 異步代發隊列與私卡每日額度熔斷

技術交付：Redis Stream + Worker Pool + 銀行額度狀態監控

7. SAGA 分散式事務與補償調度器

將遊戲廠商（PG, SA, EVO）下注與派彩轉化為 SAGA 模式；遇到廠商 API 回調逾時時，自動發起預約補償或安全平帳。

技術交付：Temporal.io / Go SAGA Coordinator + DB 冪等表

8. 嚴格冪等鍵與分散式 Redis 鎖

每一筆 `transaction_id` 在進入錢包變更前，強制取得 `Redlock`；底層資料庫設定唯一索引（Unique Constraint），防高頻重放。

技術交付：Redis 分散式鎖 + MySQL InnoDB 嚴格約束
