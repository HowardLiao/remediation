現狀缺陷：超管後台缺乏硬性綁定 TOTP / Google 2FA 機制，預設弱口令（如 admin/123456）遍布；未設計自適應登入環境防禦（如 IP/地理變更指紋阻斷）。

潛在後果：易遭自動化字典撞庫或社交工程攻破；一旦後台失守，攻擊者具備手動調帳（增加額度）、竄改出金地址與一鍵下架遊戲的最高特權。

現狀缺陷：重度依賴泰國本地少數三方 PromptPay 與私卡輪換通道，無多節點智能承兌清算與無縫備援機制。

潛在後果：泰國央行或商業銀行高頻風控凍結商戶帳戶時，前台產生大面積「掉單（已扣款未到帳）」與出金嚴重積壓，導致玩家恐慌提現擠兌與運營中斷。

現狀缺陷：下注扣款（Debit）與結算（Credit）採用簡單 HTTP Webhook 同步等待，缺乏分散式事務（SAGA / Event-driven Queue）補償機制。

潛在後果：高峰期（週五晚或熱門賽事）遊戲廠商（PG / SA）API 延遲或抖動時，極易出現「錢包餘額已扣但未進遊戲局」，或「中獎後派彩未即時結算回主帳戶」的客訴糾紛。

現狀缺陷：僅依賴提款時人工流水審核與同 IP 查詢，缺乏毫秒級串接行為特徵引擎（如跨平台真人對稱下注、卡免費旋轉 Feature-buy 刷水）。

潛在後果：專業黑產羊毛黨利用高頻腳本批次領取首存紅利，快速對沖洗白離場，待人工提款審核察覺時已造成平台資產淨損失。

現狀缺陷：標準套版前端打包未經深度混淆，打包文件常暴露真實後台管理路徑、未發布測試 API 接口及內部代理規則變數。

潛在後果：大幅降低滲透者刺探源站真實 IP 與直接繞過前端向 API 伺服器提交越權請求的難度。

現狀缺陷：無 MGA / UKGC 牌照框架，缺乏負責任博彩限制（自限下注、強制冷靜期）與合規 KYC 鏈條。

潛在後果：資產流動完全處於地下灰產管道，易遭泰國網絡警察全面查封主機與通緝，生命週期短暫（平均僅 3~6 個月）。
